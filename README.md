# Exploratory Data Analysis Project

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a dataset to find patterns and insights.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Key Analysis
- Data Cleaning
- Handling Missing Values
- Outlier Detection
- Data Visualization

## 📂 Dataset
The dataset used in this project is the Traffic Detection Project dataset sourced from Kaggle. It consists of a large collection of real-world traffic scene images, primarily captured from traffic cameras in various cities in Turkey under diverse road conditions and viewpoints. These images feature a wide range of traffic environments, lighting conditions, and object types such as vehicles (cars, buses, motorbikes, etc.) and pedestrians, making it suitable for training and evaluating computer vision models for object detection tasks. The dataset includes properly labeled annotations that can be used for detecting and localizing different traffic objects, which is essential for developing and benchmarking models aimed at traffic monitoring and intelligent transportation systems.
## 📈 Conclusion
From the analysis, it is evident that customers with higher income tend to spend more.
Seasonal trends indicate increased sales during specific months.
These insights can help businesses optimize marketing strategies and improve revenue.
